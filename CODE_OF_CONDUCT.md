# Code of conduct

SymQ is a small research project. Everyone who takes part in it — in issues, pull requests,
reviews and any other project space — is expected to help keep it a place where technical work can
be discussed openly.

## Expected behaviour

- Discuss the work, not the person. Criticism of a proof, a benchmark or a patch is welcome;
  personal attacks, insults and harassment are not.
- Be precise and honest about what a result establishes. Report negative results and failures as
  readily as successes.
- Assume good faith, and accept that a maintainer may decline a contribution.
- Respect privacy: do not publish other people's private information, private circuits or
  credentials.

## Unacceptable behaviour

Harassment, discriminatory language or imagery, sexualized attention, threats, deliberate
intimidation, sustained disruption of discussions, and publishing someone's private information
without permission.

## Reporting

Report a problem to the repository maintainer privately through GitHub (the maintainer's profile
is linked from the repository page). Do not open a public issue for a conduct report. Reports are
handled confidentially.

## Enforcement

The maintainer may edit or remove comments, commits, issues and other contributions that break
this code of conduct, and may block a participant from the project, temporarily or permanently.

For security reports, use the [security policy](SECURITY.md) instead.
