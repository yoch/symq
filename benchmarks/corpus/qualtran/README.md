# Pinned public Qualtran GF(2^m) measurement cleanup imports

These two autonomous development fixtures were generated by traversing live
`CompositeBloq.iter_bloqsoqs()` connections of the public Qualtran bloqs
`GF2Multiplication` and `GF2MulMBUC`, installed from exact commit
`638777fac4379bc62e2a1e4a52cf1a1753895d48` of
<https://github.com/quantumlib/Qualtran>. This is an actual decomposition import,
not an independently reconstructed multiplication algorithm labelled as one.

Upstream source: `qualtran/bloqs/gf_arithmetic/gf2_multiplication.py`,
SHA256 `c9542e34532eb3ca978a3405a9947c5e49c522d519834f5d5feac1051387b229`.
That hash was compared against the public file fetched at the pinned commit.
The generator checks both installed direct-URL commit metadata and this source
hash, then traverses Split, Join, Allocate, actual CNOT/Toffoli decomposition,
MeasureX, Parity, classically controlled CZ and classical Discard. Every other
bloq fails closed. Output rewiring is realized by explicit swaps when needed.
Normalized stream hashes, exact decomposition traces and their hashes, bit
order, tool versions and contracts are retained in each JSON file. Hashes make
the artifact inspectable and detect changes; the fixture loader alone is not
a cryptographic authentication of remote execution or a proof certificate.

## Preparation and coherent comparison

For degree m, the program starts with **2m arbitrary coherent data wires**
holding x,y, plus m zero ancillas. The imported GF2Multiplication preparer
computes the product into those ancillas. The reference then applies the
exact inverse of that imported reversible preparer; the candidate instead
applies the imported GF2MulMBUC measurement cleanup.

The upstream cleanup consumes each result wire with MeasureX, returning only
x,y and discarding the classical record. SymQ HMR implements the same X-basis
measurement and returns the consumed physical wire in a terminal zero state.
The generator verifies that each result wire is consumed once and has no
later quantum use. This explicitly embeds the smaller upstream output space
into x,y plus m terminal zeros. Full-channel equality under this embedding is
checked on **all** input coherences: 16 pairs for m=1 and 256 pairs for m=2.
Applying cleanup to arbitrary unprepared x,y,result is not the contract and
is not claimed equivalent to identity.

The tests include missing correction, incorrect outcome parity, wrong event
and input-bit-order mutants. Missing correction preserves every basis-state
output while dephasing coherent inputs, so it is rejected only by checking
off-diagonal matrix units. These are tiny exhaustive semantic qualification
cases, not a performance benchmark or an untouched external holdout.

## Optional regeneration

Normal installation and tests have no Qualtran dependency. To regenerate:

```sh
python -m venv /tmp/symq-qualtran
/tmp/symq-qualtran/bin/pip install 'qualtran @ git+https://github.com/quantumlib/Qualtran.git@638777fac4379bc62e2a1e4a52cf1a1753895d48'
PYTHONPATH=src /tmp/symq-qualtran/bin/python tools/generate_qualtran_fixtures.py
PYTHONPATH=src python -m pytest -q tests/test_qualtran_import.py
```
