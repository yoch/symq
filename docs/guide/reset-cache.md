# Reset-prepared monomial cache with one private HMR result

The research `symq.labs.reset_cache` checker proves a bounded local channel
identity. The reference is a signed basis permutation with deterministic classical
feed-forward. The candidate adds one quantum wire, explicitly resets it before
any use, and uses one unconditional HMR on that wire. Its new classical result
is private and forgotten. All original quantum and classical outputs are retained.

The theorem is **candidate = reference tensor reset(new wire)** as a channel on
arbitrary coherent data and an arbitrary entangled external frame. The new wire
may arrive dirty or correlated: both sides include reset, whose Kraus projectors
are factored out. After that reset, every candidate HMR column must equal the
reference column divided by sqrt(2), including its sign and original classical
outputs. Equality of these operators extends to matrix units by linearity.
Merely checking basis populations would miss relative phase errors.

```python
from symq.experimental.hybrid import HOp
from symq.hashing import canonical_sha256
from symq.labs.channel_composition import HybridFragment
from symq.labs.reset_cache import cache_request, prove_reset_cache, replay_reset_cache
from symq.resources import Budget

reference = HybridFragment(3, (HOp('ccx', (0, 1, 2)), HOp('ccx', (0, 1, 2))))
request = cache_request(reference, (0, 1))
pin = canonical_sha256(request)  # retain independently of the receipt
proof = prove_reset_cache(request, expected_request_sha256=pin, budget=Budget(max_seconds=5))
assert proof['outcome'] == 'equivalent'
assert proof['clean_entry'] == 'proved_by_explicit_reset'
assert proof['measurement_version'] == 1
assert not proof['global_substitution_authorized']
assert replay_reset_cache(request, proof, expected_request_sha256=pin) == proof
```

The closed version-1 request embeds both fragments, a private slot name and a
request pin. It reuses the existing hybrid fragment grammar and its classical
initialization/definition rules. Every declared classical input is universally
enumerated, with its current value updated by stores, inversions and XOR. Negative
conditions mean Boolean negation. Reads before definition and reuse of the new
HMR destination fail closed. A source slot name and its version are different
identities; the new result has exactly one definition, version 1.

The local grammar accepts X/CX/CCX, SWAP/CSWAP, Z/CZ/CCZ, NEG, stores, invert and
classical XOR, with the existing allowed conditions. Only the first operation may
reset, unconditionally on the new wire; exactly one HMR measures/resets that wire.
Other resets/measurements, arbitrary rotations and superpositions generated by H
are refused. Quantum data is nevertheless allowed to enter in arbitrary coherent
states. Up to 12 data wires and four arbitrary classical inputs are admitted;
request bytes, operations and total column steps are bounded. One inherited wall
deadline covers parsing, validation, both branches, dependency hashing and replay.
Expiration is inconclusive and carries no established resource facts.

The helper constructs a two-CCX cache recipe but proves nothing by construction.
Fresh proof may reject an overwritten product or a missing phase correction.
Some syntax mutants remain equivalent and are accepted after proof. A local
witness is explicitly labeled local; it is not automatically a legal global input.
Failure of the sufficient signed-column criterion returns `not_proved`, with
`failed_criterion=signed_column_identity_only`. It does not establish channel
inequivalence: for example, a global NEG changes every column's sign while
leaving the channel unchanged. The site adapter classifies this refusal as
`local_obligation_failed` and does not infer a global counterexample.

Replay reconstructs all columns and compares the complete typed receipt and code
identities. This remains an executed decision with replay, not an independent
certificate. It does not allocate a global wire/bit or prove a source splice.
A source adapter must separately bind the complete source, window, local/global
maps, original domain, fresh resources, empty outer condition stack, exact common
context and the fact that the new measurement is never read outside the window.
Adding a wire also changes physical width and requires a new complete cost record.

dirty/coherent extra-wire inputs. The synthetic serial randomized benchmark covers

## Complete KMB source binding and streaming candidate

`symq.labs.kmb_reset_cache` connects the local theorem to a complete pinned source.
Its closed version-1 site request supplies `source_file_sha256`, raw `window`, two
raw CCX coordinates in `pair`, explicit data `wires`, the next source indices
`fresh_wire`/`fresh_bit`, and the complete pinned `local_request`. `domain` must be
`all_original_quantum_states_and_arbitrary_classical_values`, and `observation`
must be `all_original_outputs_new_hmr_result_forgotten`. No initial zero is assumed.
Source and site-request hashes are supplied independently to the API.

The adapter copies/hashes the full source and reuses the resource-frontier vector
validator for all packets, instruction enums, counts, aliases and operand bounds.
It accepts that adapter's global grammar (including conditions, phases, resets and
HMR), refusing Z_POW, debug or unknown instructions anywhere. It streams from the
origin to reconstruct counts and the condition stack at both window cuts. Empty
POP is a no-op. A nonempty outer stack at either cut or PUSH/POP inside the selected
window is refused. Local original resets/HMR remain outside this milestone.
Flat conditional signed-monomial instructions use arbitrary incoming classical
bits and their actual local updates, through the existing hybrid grammar.

The **complete** window, including every INFO_TAG, is reconstructed. Its support,
wire order, original fragment and exact generated replacement must match the
request with strict types. The local checker runs freshly, and the cache product
at HMR is also exhaustively compared with the consuming controls. Constancy of
dependencies alone is never used as that relation proof. The fresh global quantum
and classical indices must equal the original header widths. The complete operand
audit proves their absence from every original instruction, including the suffix.
The replacement explicitly resets the added wire, computes/uses its cache, measures
it with HMR and corrects its phase. Its temporary value need not stay zero.
The new bit has one definition, version 1, with all reads later and inside the
window. Receipts distinguish original and candidate raw coordinates.

For a request dictionary `request` and independent pins, the API calls are:

```text
prove_kmb_reset_cache(source, request,
    expected_source_sha256=source_pin, expected_request_sha256=request_pin,
    output_path=new_candidate_path, budget=Budget(max_seconds=...))
replay_kmb_reset_cache(source, request, receipt,
    expected_source_sha256=source_pin, expected_request_sha256=request_pin,
    candidate_path=new_candidate_path, budget=Budget(max_seconds=...))
```

The optional output is a **complete** KMB, produced by changing the header and
only the bounded operation/operand spans. Register metadata, INFO_TAG order and
all outside-window packet spans remain byte-identical. Emission uses a private
staging directory beside the requested output. Only after the complete proof,
source snapshot closure and verification session's final deadline check does an
exclusive atomic link publish the finished candidate. An existing destination,
including one created concurrently, is never replaced or removed by the call.
Publication is the commit point; no later budget check attempts to roll it back.
Failed or expired emission cleans only the private staging directory.
Without output, the same stream is hashed without writing a candidate. Replay
rebuilds source extraction, resource obligations, local proof and candidate bytes;
it can also rehash an actual candidate. The opened candidate must be a regular
file with the reconstructed size; reads are bounded to that size plus one byte
to detect drift. FIFOs and devices are refused before reading; nonblocking open
also prevents waiting for a FIFO writer before that validation. No serialized
index handle is trusted.

The composition rule is explicit: the local channel identity holds on arbitrary
cut data, classical inputs and entangled frames; the identical hybrid prefix and
suffix preserve it. The new wire is absent from both, and the new classical result
is not read by them. Thus the complete candidate equals the complete original
tensored with reset on the added wire, with the new result forgotten. This proves
a channel extension, not equality of the two different full classical interfaces.
It remains a replayable executed proof, not an independent certificate or an
automatic allocation, promotion, official verification or submission permission.

Caps are 2 GiB/100 million source operations, 4096 raw window operations, 12 local
data wires and the local column-step caps. One inherited deadline spans full copy,
validation, extraction, local proof, cache relation, dependency hashing and optional
application. A cooperative deadline is not a process RSS cap. The source snapshot
uses temporary disk of source size; an emitted candidate also occupies its full
size in private staging until publication. Publication requires hard-link support
on the output filesystem and fails closed if that operation is unavailable.
Buffers are bounded independently of prefix length. There is no persistent hybrid
index or cold-cache performance claim.

The independent full-circuit Kraus oracle compares all matrix units of a small
source/candidate, with original HMR, classical feed-forward and an arbitrarily
dirty/correlated added wire. Source-context, mapping, resource index, replacement,
receipt and candidate mutations are refused; expiry emits no applicable result.

A failed local column proof is a refusal of this sufficient composition rule.
Its witness remains local: the adapter does not announce a global counterexample
without proving reachability through the complete prefix.
