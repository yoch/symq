### B — P0 research: eliminate provably redundant resets and exploit affine input relations

**Issues:** [#140](https://github.com/yoch/symq/issues/140), [#144](https://github.com/yoch/symq/issues/144), [#100](https://github.com/yoch/symq/issues/100). **Handoff:** [next-wave-hybrid-resets.md](../audit/next-wave-hybrid-resets.md).

**First theorem candidate.** For an actually proven legal input projector `P`, a CPTP prefix `Φ`, and the error observable `Q_1 = |1⟩⟨1|_q ⊗ I`, the exact statement `P Φ*(Q_1) P = 0` establishes zero population of `|1⟩` at that cut for any input supported on `P`. By positivity, the qubit is actually in `|0⟩` and uncorrelated, permitting a **known-zero** reset elimination *in the stated fragment*. A general reset remains a CPTP operation, never assignment to zero.

Use affine binary support `z = offset ⊕ B u` only with validated rank and source-derived support. Factor branch events only after proving their input-independence / zero-effect criterion; do not erase Z measurements or HMR merely because diagonal outputs agree. Cross-check complete small density-matrix units, dirty borrowed wires, output and observed instrument obligations.

**Targets, not delivered claims:** shape a self-contained, synthetic 40-physical-target / rank-35 coherent-domain experiment with 89 reset sites; show whether exact symbolic proof can avoid enumerating `2^89` histories on a family of actually proven-clean reset sites. Bound symbolic term count, memory, runtime and explicit refusal cases. Mutate a reset to make a wire nonzero and mutate a phase or classical event to preserve basis outputs but break coherence. No private loader, and no presumption that today’s `hmr_table_contract` can handle a 40-bit target (its current target cap is 12).

**Stop/go:** correctness under a bounded oracle first; performance only after a theorem and source provenance. If no win over `anchored_stream` / `affine_table` with complete cost included, publish a negative study rather than a speculative new default.

## External techniques worth testing, not claims of novelty

- [Hoare meets Heisenberg (Quantum, July 2026)](https://doi.org/10.22331/q-2026-07-23-2172): backward proof of safe ancilla disposal. This motivates B, but the source’s theorem/circuit grammar is not identical to SymQ.
- [Compile-Time Simplification of Classically Controlled Operations (2026)](https://arxiv.org/abs/2605.28439): symbolic classical-feedforward propagation. Use as a comparative design lens, not an implementation dependency.
- [Path-Sum + Weighted Model Counting / QuPRS (TACAS 2026)](https://arxiv.org/abs/2604.24504): hybrid algebraic simplification and semantic residual decision, a competitor/next-stage research reference; do not rebuild as SymQ's first priority.
- [MQT QCEC](https://github.com/munich-quantum-toolkit/qcec): reference only for genuinely shared equivalent theorem classes.
- [Lean verified LRAT](https://leanprover-community.github.io/sphere-eversion/docs/Std/Tactic/BVDecide/LRAT/Checker.html): reuse existing formal proof technology where appropriate, rather than claiming to invent LRAT.

## Execution gates (all tracks)

1. Each agent re-reads owner/repo, main SHA, branch/head, actual diff, reviews, threads and CI. Every test belongs to an exact Git tree. No local clone is assumed synchronized.
2. Use isolated research branches and Draft PRs. Never mutate `main` or another agent's branch. No automatic merge, package release, default engine change or API promise.
3. Fix the theorem statement and declared support/frame **before** implementing; positive decisions require independent proof/witness or a sound qualified engine. Ensure negative mutants are truly semantic differences.
4. Logs include tested SHA/tree/binary, source and license, commands, environment, case eligibility, positive/negative/unsupported/inconclusive, skip reasons, time/resource usage, external baseline and confidence limits.
5. Source findings are independently reviewed with a second set of oracle code, not merely successful CI.
6. Research can end with a precise negative result; stop rather than adding a complex backend without coverage/benefit.
7. Separate *correct*, *tested*, *reviewable*, *mergeable*, and *authorized to merge*. Publication requires separate explicit authorization.
