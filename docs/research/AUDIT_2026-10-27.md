# Independent audit of `5bfd6f0`: findings and resolutions

Source: the read-only audit delivered on 27 October 2026 against
`5bfd6f0f482968a762d26ac056fabf61fa4e6489`. Each finding was reproduced on current `main`
before any change; the eight proposed red tests are now part of `tests/test_audit_regressions.py`
and pass.

| id | severity | finding | state |
|---|---|---|---|
| F1 | P1 | `PhaseProgram.ops` was not validated, so a hand-built `Op` could be certified | **fixed** |
| F2 | P1 | packed products were materialised before any budget check | **fixed** |
| F3 | P1 method | QCEC timing included the conversion while claiming to exclude it | **fixed** |
| F4 | P1 research | `symq.phase` uses no `Algebra` backend, no budget, no external HMR corpus | **open, follow-up** |
| F5 | P2 | arbitrary OpenQASM `include` directives were silently accepted | **fixed** |
| F6 | P2 | `Stats.products` counted some products twice and others not at all | **fixed** |
| F7 | P2 | `--allow-dirty` recorded neither a patch nor a source digest | **fixed** (new blind split remains research work) |
| F8 | P3 | `ANF(set)` kept a mutable set; `variable()` did not validate indices | **fixed** |
| F8 | P3 | `main` is not a protected branch | **repository setting, not code** |

## F1 — the fragment contract is now enforced at every entry point

`PhaseProgram.ops` is public and mutable, so the builders' guards were not enough.
`PhaseProgram.validate()` re-checks the whole list — `Op` type, nonempty tuple of distinct
qubit indices inside `0..width-1`, arity per kind, `hmr` producing the next measurement
index, `mcz_if` referring to an earlier outcome, unknown kinds, spurious outcomes — and
`phase_semantics()` calls it before interpreting anything.

The audited counter-example now raises `UnsupportedOperation`:

```python
bad = PhaseProgram(1, 0, [Op("mcz_if", (0,), outcome=-1)])   # no measurement exists
check_phase_equivalence(bad, PhaseProgram(1).z(0))            # -> UnsupportedOperation
```

Note that `mcx` on a single wire is *valid*: it is the empty product, i.e. an unconditional
flip (`x`). Rejecting it would have removed a defined instruction.

## F2 — budgets are checked while the intermediate exists

`PackedAlgebra._multiply` charges `max_terms` after each factor and checks the clock;
`_disjoint_bounds` proves the product's term count and degree exactly when the factor supports
are disjoint, so a product that cannot fit degree ≤ 2 is refused before allocating `2**k`
masks; `product()` performs the same pre-check before falling back. The audited loop over
16 independent two-term factors no longer allocates 65 536 monomials under
`Budget(max_terms=16)`.

## F3 — three separate QCEC measurements

`qcec_check_computations(left, right)` takes pre-built `QuantumComputation`s;
`qcec_check(circuit, circuit)` remains the end-to-end helper. The harness stores
`conversion_seconds`, the native check time and `end_to_end_seconds` separately, and the
report shows all three. The previous text claimed the conversion was excluded from a timing
that rebuilt it on every repetition; that claim is gone.

## F5 — includes are part of the accepted subset

`stdgates.inc` (QASM 3) and `qelib1.inc` (QASM 2) only, the header exactly once and before
any include. Anything else is `UnsupportedOperation`, so a missing or third-party include can
no longer be skipped silently.

## F6 — one product per public operation

`SparseAlgebra.product_uncounted` and `PackedAlgebra.try_product_uncounted` exist for callers
that count their own operation. `PackedFallbackAlgebra` increments exactly once per gate or
per `product()` call; the tests assert `stats.products == len(circuit.gates)` on a circuit
whose gates all need a product.

## F7 — reproducible dirty runs

`environment.json` gains `symq_modified_files`, `symq_tree_sha256` (SHA-256 over the modified
files' contents) and `symq_patch_sha256`; the full diff is written to `working-tree.patch` in
the result directory. Sealed reports display the tree fingerprint when the run was dirty.

The other half of F7 — a genuinely blind external split, since `extension` has already
influenced hypotheses — is a research decision that cannot be discharged by a code change. The
next policy must be evaluated on new external families, ideally real 2026 HMR circuits.

## F8 — Python contracts

- `ANF` coerces its `terms` to `frozenset` in `__post_init__`, so a caller's later mutation of
  the set it passed cannot change an "immutable" value.
- `Algebra._check_variable` validates the index type and range; every backend routes its
  `variable()` through it, so `variable(-1)` no longer returns the last wire.

## F4 — what is still missing, stated plainly

`symq.phase` verifies an exact fragment with immutable ANFs and no `Algebra` backend: no
adaptive representation, no time or term budget, and no external corpus of real 2026 circuits
with X-basis erasure. Until that exists, `symq.phase` must not be presented as a trusted
verifier for arbitrary imported programs, and the programme's central claim — an adaptive
backend for real HMR circuits — remains unproven.
