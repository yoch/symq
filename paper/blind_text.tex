The ratios cover only circuits that both tools complete, which favours neither side but hides
coverage. Coverage is where the blind corpus differs from the QCEC one. On \emph{simulate}, the
native loop completes \BAdderNative/\BAdderSize{} adders (largest \BAdderNativeLargest),
\BCadderNative/\BCadderSize{} controlled adders (\BCadderNativeLargest),
\BIncrNative/\BIncrSize{} incrementers and \BRandNative/\BRandSize{} random circuits, against
\BAdderBDD, \BCadderBDD, \BIncrBDD{} and \BRandBDD{} for CUDD with reordering (largest
controlled adder \BCadderBDDLargest). The variable-order experiment above shows that the
native engine finishes \BOrderRescuedList{} under some non-default order, so its adder
failures here come from the index order rather than from the representation. \BErrorCells{}
cells (modes \BErrorModes) ended with no result and no error message
(\BErrorSilent{} silent): the worker was killed by the kernel when the memory of the VM was
exhausted (the native engine has no garbage collection and no per-cell memory cap). We count
them as failures and never impute a time.}
